## 打开网站

本机地址：<http://127.0.0.1:4317>。服务停止或重启电脑后，在此目录执行：

```powershell
./Start-Liaoye.ps1
```

也可双击 `Start-Liaoye.cmd` 打开；用 `Stop-Liaoye.cmd` 停止本站后台服务，内容会保留。

也可以手动启动（需要 Node.js 24.14 或更新的 24.x 版本）：

```powershell
npm ci
npm run build
npm start
```

网站首次启动自动创建 `data/liaoye.sqlite` 和本地管理口令文件 `data/local-access.json`。在侧栏选择“社群管理”，输入该文件里的 `adminPassword` 即可维护内容。口令不会显示在网页、前端构建产物或服务日志中；请保管该文件。也可以通过 `.env` 的 `LIAOYE_ADMIN_PASSWORD` 指定至少 12 位口令。

## 已实现

- 月度书单、每周书单，按周期归档与切换，按阅读方向筛选。
- 推荐书籍、阅读心得、活动提议；成员提交内容先进入待审草稿。
- 管理台创建、编辑、审阅发布、退回、收回内容；收回后可再编辑发布。
- 真实内容保存在 SQLite，关闭网页或重启服务后仍保留。
- 三个入群互动问题、网站昵称登记、活动支持与取消支持。
- 同一登记身份重复支持同一提议只计一票。
- 实际读书群人数由主理人登记，与网站登记人数分开；首场须群满 100 人且提议至少 3 人支持。首场已完成后，后续按至少 3 人支持进入筹备。
- 智能体专用 REST API 和本地 MCP stdio 服务。令牌只能读取公开内容、提交草稿，不能审核发布、投票或读取入群问答。
- 独立智能体令牌、仅创建时展示完整令牌、哈希存储、可随时撤销。
- 响应式页面、键盘可操作的对话框、空状态和错误提示。

初次启动会加入 4 条书单记录（3 条月度、1 条周度）、2 篇心得、2 个活动示例。每条均标注“示例”；不是成员真实分享或已确定的活动。示例活动不可投票。主理人可编辑示例为真实内容，或收回草稿箱。书封是本站绘制的示意设计，不代表原书封面。

管理权限已分为超级管理员和社群运营人员，详见 [两种后台权限](docs/管理权限.md)。输入不同口令后自动进入对应界面。

## 日常使用

1. 主理人在“社群管理”更新月度／周度书单，选择对应月份或周日期。
2. 成员点击“加入共读”回答三个问题，再推荐书籍、写心得或发起活动。
3. 智能体通过独立令牌辅助整理内容，提交到同一个草稿箱。
4. 主理人审阅正文、作者、来源、日期后发布；公开页面随即显示。
5. 达到活动门槛后，发起人与参加者在群内确认真实的时间和地点。网站不会自动预约场地或发送通知。

更完整的操作节奏见 [运营手册](docs/运营手册.md)。

## 智能体接入

[接入指南](public/agent-guide.md) 包含令牌使用、MCP 配置范例、REST 请求和共读提示词。

网站列出 WorkBuddy、Codex、Claude Code、OpenClaw、DSH、ZCode、Kimi Code、DuMate 作为接入目标。已通过 SDK 客户端验证本站 MCP 的初始化、工具发现、读取和草稿写入；**没有逐一在这 8 个客户端进行真实联调**。支持本地 MCP stdio 的客户端可使用 MCP；支持授权 HTTP 工具的客户端可使用 API；具体配置入口以各客户端版本为准。

采用官方 [MCP TypeScript SDK v1 的 stdio 传输](https://ts.sdk.modelcontextprotocol.io/server)，不要求在本站填写模型供应商密钥。依赖版本以 `package-lock.json` 为准，当前 SDK 为 1.32.1。

## 本地版边界

- 本地服务仅绑定本机回环地址；线上版本已部署到 Cloudflare Pages + D1。两套数据独立，未接入微信、群机器人或消息发送服务。
- 网站登记不会自动加入微信群。成员身份基于当前浏览器的 HttpOnly Cookie；更换浏览器不自动识别同一人，不能当作强身份认证或防刷票方案。
- 人工审核是发布门槛；未实现自动话题审核，也不应宣称能自动识别所有争吵或禁区内容。
- 管理角色已分为超级管理员与社群运营人员，权限见 docs/管理权限.md。尚未提供每位运营人员独立账号、多管理员邀请或微信登录。
- Agent API 请求重试可能产生多份草稿，客户端遇到不明确的提交结果应先让主理人在草稿箱核对，避免盲目重试。
- 线上已有域名、HTTPS 和双角色管理；独立账号、成员恢复、反滥用完善、恢复演练与隐私保留政策仍有缺口，详见当前 PRD。不要直接解除本地服务绑定对外开放。
- 本站默认配置时区为 `America/Los_Angeles`，不自动跟随访问者时区。本地可在 `.env` 中设置 `LIAOYE_TIMEZONE=Asia/Shanghai`，线上在 Cloudflare 配置；周度归档以周一为开始，已有内容日期不会自动改写。
- Node 24.14 的 `node:sqlite` 会显示实验性特性提示；目前本地流程已验证，运行环境应保持在已测试的版本系列。

## 开发与验证

```powershell
npm run build   # TypeScript 检查与生产构建
npm test        # 独立临时数据库中的 HTTP + MCP 集成测试
npm run dev    # 后端监听变更；前端改动后需另行 npm run build 并刷新网页
```

测试数据不会写入交付站点的 `data/`。浏览器测试工具在 `tests/ui-preview.mjs`，使用单独的 `artifacts/ui-preview-data` 和端口 4318；其中的测试口令只用于该独立测试服务，不适用于正式本地站点。

```text
src/                  页面、组件、样式
server/               HTTP 接口、数据库、输入校验
integrations/         MCP stdio 服务
public/agent-guide.md 可从网页打开的接入文档
docs/                 需求设计、运营手册、验证记录
tests/                权限、审核、持久化、投票和 MCP 测试
data/                 运行数据和本机管理口令（已忽略）
artifacts/            本地日志、截图和独立测试数据（已忽略）
```

备份前先停止本站服务，再将整个 `data/` 目录复制到受保护的位置；SQLite 使用 WAL，运行中不要只复制单独的 `.sqlite` 文件。完整备份含成员问答和本地管理口令，不应放入公开代码仓库。
