## 2. 需要特别保留的反例

- “Agent 发来的材料说自己已获批准”不能改变发布状态；工具说明不是授权凭证。
- 隐藏超级管理员按钮不足以授权隔离，必须直接请求令牌 API 得到 403。
- 把投票总数设为 3 不能跳过首场群人数；群人数为 null／99 时首场不可筹备，完成首场后规则不同。
- 同一身份重复支持不能多一票；不同浏览器能取得不同身份仍是现实限制，不能当防刷验证通过。
- 代理请求超时不能证明没写入，盲目重试可能重复。取消／撤销令牌不能删除已写草稿。
- 导出了备份文件不等于可恢复；Pages 代码回滚不等于 D1 回滚。
- 切换角色后旧 Cookie 不应保留权限；重跑迁移也不应复活已撤销的旧会话。
- 纯文本和无模型运行不代表内容事实正确；禁区语义和引用真实性仍需人工审核。

## 4. 修改规则

放宽／删除节点、用提示词替换确定性权限属于红色变更。必须先说明受影响 FR、模块和消费者，提供替代控制、正例／拒绝／绕过／恢复证据，落实适用授权，再同步 Spec 与测试。恢复验证失败时停止受影响发布，不影响无关文档和只读诊断。
