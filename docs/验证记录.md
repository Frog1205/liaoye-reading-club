## 浏览器操作

使用独立本地测试服务验证：

1. 月度和周度书单切换、按书名跨书单和心得搜索。
2. 填写入群三个问题，勾选社群边界，登记成功。
3. 成员提交心得后，公开心得页仍不可见。
4. 主理人登录、进入草稿箱审阅、确认发布后，心得出现在公开页面。
5. 十一月书单保存后可在月份下拉框切换查看。
6. 将书单改为每周慢读，选择周三 2026-10-21，正确归档到周一 2026-10-19。
7. 管理台退出后回到口令登录页，没有额外错误提示。

浏览器检查发现原月份表单显示的新值未被提交状态采纳。修复为使用带 `name` 的日期输入，在提交时从 `FormData` 读取实际值；随后跨月／跨周操作均验证通过。移除一个周期最后一本书后，周期和类别选择使用有效选项回退，避免下拉框显示与列表不一致。
