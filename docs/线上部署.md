# 聊也读书线上部署

当前产品、架构和验证基线见 [PRD](PRD.md)、[技术架构](技术架构.md)、[验证与验收](ai-native/验证与验收.md)。下文“本次验证”保留初次部署证据；后续新增双角色后，本地与云端处理器已各有 17 个场景通过。云端处理器测试用本地 SQLite 包装 D1 接口，真实云端证据单独记录。

部署账号：用户指定的 Cloudflare 账号。域名：`liaoye.veynuq.com`，DNS 保留在腾讯云 DNSPod。

## 云端资源

- Cloudflare Pages 项目：`liaoye-reading`。
- 平台域名：`https://liaoye-reading.pages.dev`。
- D1 数据库：`liaoye-reading-db`，绑定名 `DB`。
- 腾讯云记录：`liaoye` / `CNAME` / `liaoye-reading.pages.dev`，TTL 600。
- `cloud/worker.mjs` 提供云端 API，`server/` 保留本地运行方式。
- 管理会话、限流状态、内容、成员、投票与令牌摘要保存到 D1。

## 管理和智能体接入

在网站侧栏“社群管理”输入管理口令。超级管理员沿用本机 `data/local-access.json` 中已有口令，运营角色口令保存在被忽略的 `data/operator-access.json`；实际值不写入源码或部署日志。Cloudflare 保存各角色 PBKDF2 派生摘要与随机盐，管理 Cookie 具有 HttpOnly、SameSite 和 Secure 属性。两种界面与服务端权限见 [管理权限](管理权限.md)。

个人智能体使用 `LIAOYE_API_URL=https://liaoye.veynuq.com`，在管理台创建独立令牌后，按网站接入指南配置。MCP stdio 进程仍在个人客户端运行，经 HTTPS 调用云端 API，无需本机网站常驻。智能体仅能读取公开内容和提交草稿。

此版保留按浏览器登记身份的投票方式，暂没有手机号／微信验证、跨浏览器身份恢复或多管理员邀请。云端部署不代表这些功能已经实现。

## 更新和回滚

```powershell
npm ci
npm test
$env:LIAOYE_TEST_CLOUD='1'
npm test
Remove-Item Env:LIAOYE_TEST_CLOUD
npm run deploy
```

`npm run deploy` 构建前端，打包 `dist/_worker.js`，发布 Pages。配置文件 `wrangler.jsonc` 不含真实口令，更新时保留 D1 绑定与管理摘要 Secret。后台状态均在 D1，不依赖当前 Worker 内存。

需要回滚时，在 Cloudflare Pages 的部署记录中选择前一个通过验证的生产部署；代码回滚不会自动回滚数据库。

## 数据迁移和备份

本次迁移了 8 条内容记录，没有迁移本地成员问答、会话或智能体令牌。线上后续更新直接保存在 D1，与本地 SQLite 独立；不要反复把本地数据库覆盖到线上。

```powershell
npx wrangler d1 export liaoye-reading-db --remote --output artifacts/liaoye-backup.sql
```

数据库备份包含私有成员问答、会话和令牌摘要，只存放在受保护的位置。`artifacts/`、`.wrangler/`、本地数据库和环境变量文件已被版本管理忽略。

## 本次验证

- 本地流程 14 项测试通过；云端处理器复用相同 14 项测试全部通过。
- 平台地址实测：首页与 D1 API 返回 200，管理登录成功，Secure Cookie 生效。
- 通过真实云端接口创建临时令牌并提交草稿；跨请求读取草稿箱确认持久化；公开列表不包含草稿；随后退回自检草稿并撤销令牌，令牌再次读取返回 401。
- 自检记录留在已退回列表、令牌留在已撤销列表，均明确标注为部署自检；不作为真实社群分享。
- 域名和 HTTPS 的最终验证结果见 `artifacts/cloud-domain-verification.json`。
- 最终正式域名状态为 Active，首页、健康接口、书单接口、接入指南均返回 200；未登录管理接口返回 401，登录后返回 200；HTTP 自动以 301 跳转 HTTPS。
- 签发过程中遇到过证书机构内部错误，经官方重试验证接口重新排队后激活。DNS 未迁移，未绕过 TLS 校验。

相关官方说明：[Pages 外部 DNS 自定义域名](https://developers.cloudflare.com/pages/configuration/custom-domains/)、[D1 数据库绑定](https://developers.cloudflare.com/d1/worker-api/)。
