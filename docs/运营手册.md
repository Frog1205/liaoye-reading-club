# 聊也读书 · 轻量运营手册

## 月初：一起选几本想读的书

主理人在管理台选择“发布书单”，填写书名、作者、推荐理由、阅读方向，周期选“月度共读”，选择目标月份。书单不必太长，先围绕成员真实感兴趣的主题选 1—3 本。原有月份会保留在周期下拉框里。

可邀请智能体汇总成员已提出的书目和理由，再提交草稿。没有成员信息时，应保留待确认项，不制造“大家都推荐”的说法。主理人核对后发布。

## 每周：留一个小问题

用“每周慢读”增加本周安排。可沿用月度书目，描述本周阅读范围、一个讨论问题、期待分享的内容。选择日期后会归档到该周周一。

建议提示词：

> 根据本月书单和我提供的进度，整理一份本周阅读安排，给出一个开放问题。不要虚构页码或章节。提交为书单草稿，等我确认。

每周邀请成员写一篇短心得，不强求完整书评。参考结构：书名 → 一个让我停下来的片段 → 我的真实体验 → 想和大家聊的问题。直接引用前核对原文。

## 每次有新朋友：回答三个问题

1. 推荐一本书，会推荐什么？
2. 除了书籍内容本身，更看重什么附加价值？
3. 使用过 AI 辅助阅读吗？

网站保存问答用于登记，不公开展示，不替代微信群加入流程。新朋友完成登记后，可提交书单／心得／活动草稿，并支持真实的公开活动提议。

## 每次审稿：确认后再公开

进入管理台查看待审内容，区分成员分享、智能体整理和示例样稿。检查署名、书籍信息、真实经历、原文依据与社群边界。点击“审阅内容”打开完整正文，必要时修改，再“确认并发布”；不合适的内容可退回。

发布后发现问题可“收回”到草稿箱，不会永久删除。之前退回的内容也可重新审阅。

## 每次活动：让想聊的人发起

主理人先登记实际读书群人数。首场需群满 100 人，并让提议获得至少 3 人支持。达到门槛后，发起人与参与者在群内确认时间、地点、人数和各自期待，网站不自动预约或发通知。

首场实际完成后，在人数设置下勾选“已完成首次线下活动”，再点“保存”。此后按至少 3 人支持共同筹备，不再反复套用首场门槛。

投票采用本站浏览器登记身份去重，仅用于当前小规模试运营；更换浏览器可产生另一登记身份，正式对外运营需换成可验证且可恢复的成员登录。

## 记录与备份

每月结束时，保留原月份书单与成员愿意公开的心得，不要求清空旧内容。每次重要内容更新后，可先停止服务，再备份整个 `data/` 文件夹。备份含成员问答与本机管理凭据，应仅保存在受保护的位置。

这里的节奏是操作建议，没有创建任何定时任务、自动提醒或群消息发送。

## 成员智能体共创（2026-10-15增量）

第一次接入时，引导成员到「智能体共读 → 第一次用Codex共读」：在本机私有环境配置令牌，复制首次指令让Codex读取指南与公开书单，再选书讨论。无需先装Skill或给成员网站源码。成员没有真实笔记时先共读，不要自动生成虚构心得投稿；内容确认好再使用「复制提交草稿指令」。创建令牌弹窗保存后也可跳到首次引导。

成员注册登录后，在「智能体共读 → 我的个人令牌」自行创建，或从社群账号页点击「我的个人令牌」。无需管理员代发。每人最多5枚有效，名称建议按工具/设备区分；完整值仅显示一次，存到智能体私有环境变量。完成入群问答后可提交书单、心得及活动草稿，仍由运营审阅发布。本人随时撤销，泄露时也可联系超级管理员应急撤销。详细配置见[接入指南](../public/agent-guide.md)。
